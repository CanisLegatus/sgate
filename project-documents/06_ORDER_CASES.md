# Разбор конкретных товаров — первая подборка

**Исторический срез до добавления КУБ.** Буквы полей ниже сохранены как в исходной подборке, не применять их к новой схеме. Новый допуск по кубу для всех семи SKU проверен в [07_CUBE_AUDIT.md](07_CUBE_AUDIT.md). Числовые решения владельца сохраняются как примеры, но в будущем всегда предваряются проверкой куба.

Источник: `example-files/order-full.xlsx`, заказ от 01.11.2026. В шапке дата 01.11.2026. По последующему правилу ближайшая поставка для заказа в этот день — четверг 05.11.2026, следующий четверг — 12.11.2026; это вывод из правила владельца, не отдельная дата из файла. При запуске приложения даты считаются от текущего дня свежего заказа.

«—» показывает исходную пустую ячейку; для продаж и остатков её расчётное значение по последующему уточнению владельца — 0. Особенно важно для остатка V, недельных продаж и рекомендаций Y. Поля W/AB приведены как показатели Web-заказа; их формулы не установлены. Последующее уточнение владельца: K является обязательной кратностью без исключений. Это исходные показатели Web, а не автоматически воспроизведённые решения движка. Первая реализация описана в 10_IMPLEMENTATION.md.
