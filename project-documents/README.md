# Документация проекта sgate

Актуальность проверена 02.11.2026. Для новой сессии начать с [AGENTS.md](../AGENTS.md) и [состояния](PROJECT_STATE.md).

## Источники истины

1. Последние явные решения владельца в переписке и его письменные пояснения задают бизнес-смысл. Новое решение может отменить старое.
2. Текущие XLSX задают фактические поля/значения. Web-рекомендации не гарантируют соблюдения правил владельца.
3. Документы — зафиксированное представление этих источников. Актуальные правила ведутся в 05; журнал решений содержит исторические этапы, а не конкурирующую спецификацию.

Различать: подтверждено владельцем; наблюдается в данных; техническое/математическое следствие; предложение агента; неизвестно. Не дописывать недостающие коэффициенты и исключения как слова владельца.

## Термины текущей схемы

SKU/артикул — идентификатор товара; УМ — управляющий; Z «Рек» — рекомендация Web; AA «Заказ УМ» — ручное переопределение; AB — итог. I — куб товара, Y — куб магазина. МТЗ — показатель потребности выкладки/запаса, формально раскрыт не полностью и обычно игнорируется владельцем. «Газета» — промо, способное временно изменить спрос.

Целевой формат продукта утверждён: HTML/JavaScript без сервера. Первая рабочая версия интерфейса/движка реализована; это не означает, что все пограничные случаи согласованы. Исследовательские команды и тесты — в [корневом README](../README.md).
