## Пустоты и типы

Пустые числовые показатели означают 0 по прямому ответу владельца, особенно продажи/остатки. На уровне чтения исходные пустоты сохраняются для аудита. Не превращать даты, текст и кубы в число 0. Пустое ручное AA — отсутствие команды, а не команда обнулить исходную рекомендацию. K=0 недопустимо для расчёта кратности.

Даты Excel нужно декодировать с учётом системы дат книги; не сравнивать serial как обычное количество. Четыре недели упорядочены, но их календарные границы не установлены. Не выводить их из дня поставки.
