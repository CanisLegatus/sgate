# Текущее состояние проекта

Обновлено 02.11.2026. Пользователь поручил за одну итерацию сделать рабочее приложение. Первая версия реализована.

## Запуск

Открыть `sgate.html` в Chrome/Edge двойным щелчком. Один файл со встроенными JS/CSS/SheetJS, без сервера/интернета/установки. Исходный entry — index.html; приложение — app/engine.js, importer.js, session.js, main.js, styles.css. Подробности в [10](10_IMPLEMENTATION.md), актуальные бизнес-правила в [05](05_BUSINESS_RULES.md).

Работают импорт Excel по заголовкам/фактическим ячейкам, оба формата, кубы и запреты, прогноз, четверги, поставки, кратность, индивидуальные цели/стратегии, ручные решения, базовые замены, фильтры/карточки, метрики 352 м², автосохранение решений, JSON-сессия, CSV изменений и Excel-отчёт. Оставить исходный Web не создаёт ручную запись; свои количества проверяются. Явный 0 сохранён в экспорте. Отправка в Web не автоматизирована.

## Проверенные факты и данные

Исторические 7 решений владельца 0/1/56/2/0/6/24 остаются допустимыми, сохраняются/экспортируются, не зашиты в движок по артикулам. Это не обещание автоматического воспроизведения этих количеств новой взвешенной формулой. Сценарии A/B/C проверяются отдельно; B=70 сегодня, в схематическом недельном календаре 30 к первому четвергу и дефицит до второго, заказ 56 даёт 86→46.

В реальном файле отрицательные недельные продажи у 249-110/314-140/822-288 и отрицательные дни запаса у двух из них. Исходные значения сохранены; автоматический прогноз этих товаров требует ручной оценки, а не скрытого зануления. Суммы недель после сохранения знака совпадают с U. Четыре исходных конфликта Web K/L сохранены как факты; согласованный Web не переписывается, наши корректировки обязаны соблюдать правила.

## Технические допущения первой версии

Цель/равномерный расход/дата AE по умолчанию/округление описаны в интерфейсе и 10 как технические стартовые решения. Пользователь может менять цель/прогноз/дату партии/количество. Пики не очищаются, только отмечаются. Промонедели не угадываются: до разбора промо автопредложение не принимается, можно задать ручной прогноз/разметку или собственное решение. Простые замены поддержаны, цепочки/неизвестные связи требуют проверки.

## Проверки и продолжение

Node-тесты движка и browser-тесты file:// выполняются через npm, Python-аудит остаётся. Browser tests используют системный Chromium; артефакты в analysis/browser и test-results исключены из Git. Финальная проверка: 24 Node-теста, 6 браузерных тестов file:// и 10 Python-тестов прошли. Проверены экспорт CSV/Excel с нулём, восстановление сессии, полная выгрузка и отсутствие сетевых запросов. Не выдавать это за доказательство безошибочности всех будущих заказов.

Следующий пользовательский этап — открыть полную свежую выгрузку, проверить предложения/удобство и уточнить стартовые целевые нормы на фактических решениях. Список бизнес-неопределённостей — в 04; версия реализована, но эти вопросы не выдуманы как закрытые.

Публичный репозиторий https://github.com/CanisLegatus/sgate. Excel, analysis с массовыми исходными данными/комментариями, JSON-сессии, CSV и тестовые снимки не публикуются.
