# Текущее состояние проекта

Обновлено 02.11.2026. Исправлены главный экран и расчёт после замечания о тысячах строк и швабре; версия правил sgate-1.1.

## Запуск

Открыть `sgate.html` в Chrome/Edge двойным щелчком. Один файл со встроенными JS/CSS/SheetJS, без сервера/интернета/установки. Исходный entry — index.html; приложение — app/engine.js, importer.js, session.js, main.js, styles.css. Подробности в [10](10_IMPLEMENTATION.md), актуальные бизнес-правила в [05](05_BUSINESS_RULES.md).

Работают импорт Excel по заголовкам/фактическим ячейкам, оба формата, кубы и запреты, прогноз, четверги, поставки, кратность, индивидуальные цели/стратегии, ручные решения, базовые замены, фильтры/карточки, метрики 352 м², автосохранение решений, JSON-сессия, CSV изменений и Excel-отчёт. Оставить исходный Web не создаёт ручную запись; свои количества проверяются. Явный 0 сохранён в экспорте. Отправка в Web не автоматизирована.

## Технические допущения первой версии

Цель/равномерный расход/дата AE по умолчанию/округление описаны в интерфейсе и 10 как технические стартовые решения. Пользователь может менять цель/прогноз/дату партии/количество. Пики не очищаются, только отмечаются. Промонедели не угадываются. Старая метка акции не блокирует достаточный Web автоматически; существенная неопределённость требует ручного прогноза/разметки или решения. Граф замен выявляет циклы/цепочки, карточка показывает участников; неоднозначные группы требуют осознанного сохранения единственного положительного Web либо явного выбора артикула. Два положительных заказа запрещены.
