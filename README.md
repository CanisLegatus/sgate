# sgate — помощник товарного заказа

Рабочее локальное приложение для проверки Web-заказа «Галамарта». [Репозиторий](https://github.com/CanisLegatus/sgate).

## Запуск

**Откройте [sgate.html](sgate.html) двойным щелчком в Chrome или Edge.** Нужен только этот файл: сервер, установка программ и интернет не требуются. На GitHub сначала скачайте файл через Raw / Download raw file, а не страницу просмотра кода. Можно также открыть `index.html` из полной папки проекта.

1. Загрузите свежий Excel. Все определённые количества сразу рассчитываются и входят в наш заказ — без согласований.
2. Откройте списки «Проблемные», «Уменьшено», «Увеличено», «Обнулено», «Без изменений» или «Все изменения». В таблице рядом видны исходный Web и наш заказ.
3. Выберите общую стратегию над таблицей и процент: все товары пересчитаются сразу. Смена стратегии/процента сбрасывает ручные количества; это подписано у настройки.
4. В карточке можно изменить количество, прогноз/цель/дату партии или вернуть автоматический расчёт. Правка сразу попадает в заказ и выгрузку.
5. «Выгрузить заказ» создаёт CSV всех изменений либо Excel со всем заказом и проблемами. «Сохранить сессию» — JSON для продолжения. Финальный перенос и отправка — в Web-заказе лично.

**«Нужны данные» — не ноль.** У таких строк неизвестно количество: они выделены, не подменяются Web и не входят в CSV изменений. Excel показывает их на листе «Проблемные». Остальные товары рассчитываются независимо.

## Что работает

- Импорт всех реальных ячеек Excel по заголовкам, включая выгрузки с ошибочным dimension и новую колонку КУБ.
- Абсолютные запреты, кубовый допуск, кратность и доступность для наших корректировок, автоматическое уменьшение/увеличение/обнуление вместо слепого сохранения Web.
- Прогноз 10/20/30/40, календарь двух четвергов, резерв 25% защищённым товарам, уже едущие партии без двойного учёта.
- Поиск, фильтры, пагинация, карточки, стратегии, ручной прогноз/разметка промонедель, группы замен и явные объяснения. Циклы показаны одним конфликтом; выбор артикула явный, два связанных товара одновременно заказать нельзя.
- Наполнение на 352 м² в SKU и розничных рублях, проект заказа, текущие/прогнозные остатки.
- Локальное автосохранение параметров и ручных количеств, полная резервная сессия, CSV и Excel с явным нулём.

Файлы обрабатываются в браузере, сеть для расчёта не используется. Автосохранение не заменяет резервную JSON-копию: для автоматического восстановления откройте тот же Excel. Если корпоративный браузер запрещает localStorage, используйте JSON-сессию.

## Границы первой версии

Стартовая формула базовой цели видна в карточке и настраивается. Она является технической реализацией, а не окончательно утверждённой универсальной нормой. Пики не срезаются. Сложное промо и отрицательные исходные продажи требуют ручного прогноза/решения; автоматического угадывания нет. Старая выгрузка без КУБ доступна для просмотра, но положительные решения без установленного допуска заблокированы.

Перенос через браузерную автоматизацию не реализован; формат CSV не заявляется как импортный формат Web-заказа. Подробности формул, допущений и проверок — [10_IMPLEMENTATION.md](project-documents/10_IMPLEMENTATION.md). Актуальные бизнес-правила — [05](project-documents/05_BUSINESS_RULES.md), карта знаний — [AGENTS.md](AGENTS.md).

## Разработка и тесты

Для использования приложения эти команды не нужны. Для разработки — Node.js и npm:

```bash
npm ci
npm test
npm run test:browser
npm run build
```

Браузерные проверки используют системный Chromium `/usr/bin/chromium`; другой путь задаётся переменной `SGATE_CHROMIUM`. Тесты открывают автономный `sgate.html` через file://, без HTTP-сервера. Сборка обновляет один пользовательский файл, включая локальную библиотеку SheetJS 0.20.3 и её лицензию.

Исследовательские проверки Python 3 (стандартная библиотека):

```bash
python3 -B -m unittest discover -s tests -v
python3 -B scripts/extract_unique_values.py example-files/order-full.xlsx -
python3 -B scripts/analyze_cubes.py example-files/order-full.xlsx
python3 -B scripts/audit_order_data.py example-files/order-full.xlsx
```

Внутри Python-инструментов остаются старые логические буквенные ключи с mapping на физические поля; браузерный движок использует смысловые имена. Исторические схемы/машинные результаты сверяйте с хешем исходника.

## Локальные данные

Excel/example-files, analysis с исходными пояснениями и результатами, пользовательские JSON-сессии/CSV и скриншоты/трассы тестов исключены из Git. Данные вашего заказа не встроены в sgate.html; демо синтетическое. Ссылки документации на локальные файлы требуют собственных исходников. Без них соответствующие интеграционные тесты пропускаются. Код и документация публикуются, реальные Excel — нет.
